# Meditron API Contract

**Версия:** 0.1.0  
**Базовый URL:** `http://localhost:8000`  
**Формат данных:** JSON  
**Аутентификация:** Bearer Token  
**CORS:** разрешены источники `http://localhost:3000`, `http://127.0.0.1:3000`, `http://localhost:5173`, `http://127.0.0.1:5173`.

---

## 1. Общие сведения

API предназначен для скрининга латентных дефицитных состояний по лабораторным и демографическим данным.  
Все эндпоинты, кроме `/health`, `/api/v1/meta/*` и `POST /api/v1/screenings`, требуют аутентификации.

**Роли пользователей:**
- `patient` — пациент;
- `doctor` — врач.

**Формат ответа об ошибке:**
```json
{
  "detail": "Описание ошибки"
}
